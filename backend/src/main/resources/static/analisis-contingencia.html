Análisis de Contingencia (Paso a Paso)

Procedimiento completo para determinar la independencia entre dos variables cualitativas.

PASO 1: Tabla de Frecuencias Observadas (FO)

Se agrupan los datos cualitativos y se cuenta la frecuencia de cada combinación.
PASO 2: Tabla de Frecuencias Esperadas (FE)

FE = (Total Fila × Total Columna) / Total General. Representa lo que se esperaría si las variables fueran independientes.
PASO 3: Cálculo del Estadístico Chi-Cuadrado

X² = Σ (FO - FE)² / FE. Se muestra la contribución de cada celda al estadístico total.
